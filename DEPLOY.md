# Deploy & Monitor FreshCart

This project is containerized with Docker, published to **GitHub Container Registry (GHCR)**, deployed on **Render**, and monitored with **UptimeRobot** plus the app `/health` endpoint.

## Architecture

1. Push to `main` runs GitHub Actions: tests → Docker build → push to GHCR.
2. Render pulls `ghcr.io/23c132-sairathna/freshcart:latest` and serves the app.
3. Render health checks `GET /health`.
4. UptimeRobot polls `/health` for external uptime monitoring.

## Image registry (GHCR)

After a successful push to `main`, the image is available at:

```text
ghcr.io/23c132-sairathna/freshcart:latest
ghcr.io/23c132-sairathna/freshcart:<git-sha>
```

**Make the package public** so Render can pull without credentials:

1. Open the GitHub repo → **Packages** → `freshcart`
2. **Package settings** → **Change visibility** → **Public**

## Deploy on Render

1. Create an account at [https://render.com](https://render.com)
2. **New** → **Blueprint** → connect this GitHub repository
3. Apply [`render.yaml`](render.yaml) (service name `freshcart`, health check `/health`)
4. Confirm env vars:
   - `SECRET_KEY` — auto-generated by Render (or set your own)
   - `DATABASE_PATH=/tmp/freshcart.db` (ephemeral SQLite on free tier)
   - `PORT=8080`
5. After deploy, open the Render URL, for example:

```text
https://freshcart.onrender.com
```

### Render logs and metrics

- **Logs:** Render Dashboard → `freshcart` → **Logs**
- **Metrics:** Render Dashboard → `freshcart` → **Metrics** (CPU, memory, request volume)

## Health check

```bash
curl -sS https://<your-render-host>/health
```

Expected response:

```json
{"database":"ok","service":"freshcart","status":"ok"}
```

## UptimeRobot monitoring

1. Create a free account at [https://uptimerobot.com](https://uptimerobot.com)
2. **Add New Monitor**
   - Monitor type: **HTTP(S)**
   - URL: `https://<your-render-host>/health`
   - Interval: **5 minutes**
   - Keyword (optional): `"status":"ok"`
3. Confirm the monitor shows **Up**
